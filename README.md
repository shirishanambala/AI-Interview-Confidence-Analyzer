# AI-Interview-Confidence-Analyzer
A real-time AI-based Interview Confidence Analyzer using computer vision to analyze facial expressions and generate insights. Built with Streamlit, OpenCV, MediaPipe, and Plotly, it captures live video via DroidCam and provides dynamic confidence scoring and session analytics.
FEATURES-
* 🎥 Real-time webcam analysis 
* 😊 Face detection & expression tracking
* 👁️ Eye contact monitoring
* 📊 Live confidence scoring 
* 📈 Performance trend visualization
* 📋 AI-based feedback (strengths & improvements)
* 🎨 Modern UI with Streamlit
* ⚡ Smooth real-time updates
TECH STACK -
💻 Frontend - Streamlit
⚙️ Backend - Python
